# 🎵 Music Instructions

Place your romantic audio files here:

- `our-song.mp3` -> The main relationship anthem that plays in the background.
- `month-01.mp3` -> Optional track for Month 1.
- `month-02.mp3` -> Optional track for Month 2.
- ... up to `month-12.mp3`.

*Note: If no audio file is provided, the website automatically plays a soothing, dreamy music-box lullaby synthesized via Web Audio API so your girlfriend immediately enjoys beautiful background melody and gentle sound effects!*
